# 单窗口，操作主屏、查看副屏

原生 macOS 工具，设备画面是主体。SwiftUI 系统字体用于操作和状态，等宽数字仅用于 display ID/尺寸。背景使用系统窗口色（浅色基准 #F3F4F6），画面舞台使用 #E7EBF0，正文 #202D3A，次要文字 #687584，选中状态 #2E63C7，正在接收帧 #247967；适配系统深色外观。

左侧约 210px 设备屏幕列表；右侧使用全部剩余空间按比例显示手机画面。工具栏提供设备选择、单屏/并排、自动跟随新副屏。默认并排，主屏用于操作，副屏用于观察；不为每块屏弹出独立窗口。主屏提供点击、拖动、滚动、键盘与剪贴板控制，以及返回、主页和多任务入口。副屏和历史画面不接收输入。

活跃副屏自动加入列表和并排舞台。主屏键盘已聚焦时，新副屏不会改变选中屏幕、滚动位置或输入焦点；未聚焦时可自动跟随。副屏休眠、移除或断连后退出主舞台，收进默认折叠的历史列表；原先选中的活动副屏结束后选回主屏。用户主动点击历史条目时才显示其最后画面和时间。

清除历史只删除本机条目和画面缓存，不操作 Android display。同一 identity 仍被设备枚举为 OFF 时继续隐藏，重新 ON 时恢复；新的 identity 不受旧屏清除状态影响。历史查看是一次明确选择，屏幕重新活跃后不沿用旧的历史查看状态。

历史画面保存在当前运行的内存中；明确导出的 PNG 和主动开启的诊断文件独立保存，清除历史不删除这些文件。保存画面是截图功能，目前不提供音频播放或视频录制。

断连、未授权、缺少依赖分别提供具体操作提示。静态页面没有新帧不等于休眠，使用系统源屏状态判断。主屏无论是否休眠都保留，供查看连接状态和主动唤醒。

屏幕发现基于 Android 系统接口，所有副屏使用一致的发现和只读观看规则。可用范围取决于设备的枚举与捕获权限。依赖准备使用本机 adb 和固定版本的官方 scrcpy 服务端；任何可选下载应明确展示来源和版本，并由用户主动发起。

设计复核：这是看设备的工作台，避免营销型大标题、装饰卡片和无关统计。只有屏幕列表、真实画面、连接状态和必要观看选项。
